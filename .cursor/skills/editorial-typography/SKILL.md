# Editorial Typography & Layout

1. Начни с содержания: какие фразы главные, какие второстепенные; не переписывай пользовательский текст без согласования.
2. Предложи до двух шрифтов: читаемый кириллический sans (например, Manrope / Onest / Golos Text) и поддерживающий кириллицу акцентный serif (например, Cormorant Garamond / Prata). Это кандидаты, не идентификация референса.
3. Проверь реальные доступные файлы и поддержку нужных глифов. Укажи fallback, систему загрузки, политику font-display.
4. Построй fluid типографику через clamp, ограничь длину строк и продумай переносы на 1440 / 768 / 390 px.
5. Сохрани контраст между display и body: курсив только на коротких акцентах, а не на длинных абзацах.
6. Для композиции используй сетку, намеренную асимметрию, выразительные отступы и чередование насыщенных и спокойных секций.
7. Не создавай горизонтальный overflow ради огромного заголовка; при необходимости адаптируй размеры, переносы и word-break.
8. Доступность: тексты читаемые, семантические H1–H3, контраст и zoom 200%, сохранён порядок чтения и табуляции.
9. Результат: блок Typography + Layout для `DESIGN.md` и список изменений; не меняй код до утверждения.
