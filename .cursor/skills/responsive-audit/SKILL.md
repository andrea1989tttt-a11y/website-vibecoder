# Responsive & Functional Audit

1. Найди реальные способы запуска проекта, тесты и среду браузерной проверки. Не утверждай «проверено», если нет инструментов.
2. Сними/просмотри 1440px desktop, 768px tablet и 390px mobile, при возможности дополнительно 320px.
3. Проверь горизонтальный overflow, наложения, обрезку крупного текста, меню, карточки, ссылки, кнопки, формы, изображения, fixed/sticky слои.
4. Убедись, что pinned горизонтальная галерея превращается в доступный свайп на телефоне.
5. Проверь `prefers-reduced-motion`, клавиатуру, focus-visible, логическую очередность чтения, alt и contrast WCAG AA для обычного текста.
6. Проверь консоль, ошибки загрузки шрифтов, broken links, работоспособность формы (без реальной отправки, если не согласовано).
7. Запусти проектные тесты/build, если они есть, без установки новых зависимостей без согласования.
8. Дай таблицу: проблема → серьёзность → исправлено/не исправлено → как проверено. Исправляй только подтверждённые проблемы; если нужен редизайн логики, запроси разрешение.
