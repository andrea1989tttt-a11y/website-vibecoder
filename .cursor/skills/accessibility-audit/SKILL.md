# Accessibility Audit

- Семантические landmarks, один осмысленный H1, структурные H2/H3, alt для информативных изображений и пустой alt для декоративных.
- Контраст текста с поверхностями WCAG AA по возможности; отдельно проверить фуксию на светлом фоне.
- Все элементы навигации и управления доступны с клавиатуры, имеют видимый `:focus-visible`; доступен skip link, если уместно.
- Не полагайся только на цвет для передачи смысла. Кнопки и ссылки имеют подписи, touch targets удобны.
- Анимации не блокируют чтение, `prefers-reduced-motion` даёт полную альтернативу без потери контента.
- Проверяй реальную доступность, не обещай сертификат соответствия. Перечисли, что тестировалось и где нужна ручная проверка.
