

Учебный проект курса «Вайб-кодинг: от идеи до запуска».

## О проекте

Создаю персональный сайт, который поможет представить себя,
рассказать об услугах, показать примеры работ и получать заявки.

## Планируемые разделы сайта

- Главный экран с именем и позиционированием.
- Обо мне.
- Услуги.
- Примеры проектов.
- Преимущества работы со мной.
- Контакты и кнопка связи через Telegram.

## Технологии

- HTML — структура страницы.
- CSS — оформление сайта.
- JavaScript — интерактивные элементы.
- Cursor — помощник для разработки с искусственным интеллектом.
