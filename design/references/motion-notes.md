# Motion notes — учебный пример MK Vision
Источник: https://mkvision.studio/ — наблюдения по записи экранной прокрутки, а НЕ исходный код сайта.

- **00:00–00:19 — hero:** крупная графическая диагональ и ощущение продолжения линии при прокрутке. Для нашего бренда создать собственную фуксиевую ribbon.
- **00:20–00:31 — typography:** сочетание огромного sans, тонкого/курсивного акцента, горизонтального marquee. Слова и композицию создаём свои.
- **00:32–00:43 — portfolio:** вертикальная прокрутка управляет горизонтальным движением широких карточек. На мобильном — свайп со snap, без pin.
- **00:44–01:12 — dark story:** контрастный тёмный фон, направления сменяются последовательно. Наши направления: сайты, AI-инструменты, автоматизации.
- **01:13–01:44 — calm end:** снижение интенсивности анимаций, FAQ и большой финальный CTA.

**Всегда:** prefers-reduced-motion, без scroll-jacking, без чужих бренд-элементов, без изменения доступности и функций сайта.
